# Roadmap

None of this exists yet, and none of it has a date. Day 0 is Episode 000 and a way to add to it.

## First missions for contributors

1. **File a transmission.** One short, strange piece of text. [No code needed](https://github.com/supernovae/signal-lost/issues/new?template=propose-transmission.yml).
2. **Post to Deep Field.** A message from a tired volunteer in 2000. [No code needed](https://github.com/supernovae/signal-lost/issues/new?template=propose-archive-entry.yml).
3. **Build a community package.** A thread of related messages, as one JSON file. Start from `content/community/first-light.json`.
4. **Play it on Firefox or Safari.** They are untested. Report what breaks.
5. **Tell us how it runs on real hardware.** Frame rate on integrated graphics hasn't been measured.
6. **Listen to it.** Sound hasn't been checked by ear. Suggest better synthesis in `src/audio/audio.ts`.

## Possible directions

- The Silent Observatory, and what "2 observers required" means.
- Community signal catalogs, and seeded but deterministic anomalies.
- Explorable stations and more 3D spaces.
- New door games and instruments reached from terminals.
- Deeper ECHO memory, and an optional model-backed `DialogueSource` that never gates progress.
- A contribution history shown inside the universe, generated from reviewed repository data.
- Restoration missions driven by GitHub issues.
- Mysteries that reference this repository's real history.
- Events tied to major releases.

## Not planned for now

Real-time multiplayer, public accounts or leaderboards, a persistent backend, tokens or monetization, mandatory AI, browser-side code plugins, and automatic merging of unreviewed contributions.
